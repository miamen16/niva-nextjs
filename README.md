# Our Climate, Our Community — Next.js

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included
- Responsive homepage and navigation
- Climate explainer and action resource cards
- Interactive five-question climate reflection quiz
- Educator, directory introduction, newsletter section, and footer

## Before production
This is a starter recreation, not a pixel-perfect clone. Artwork uses CSS placeholders, resource links currently point to the original site, and the newsletter is not connected. Add approved original assets, verified resource data, translations, and a real newsletter provider before launch.
